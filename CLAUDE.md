# House rules

Follow these in every task.

1. **Additive changes only.** Keep every existing feature, data field and prediction formula working unless the task says otherwise.
2. **Keep the current architecture.** If this is a single-file HTML PWA, keep it single-file, load libraries from a CDN with pinned versions, and add no build step.
3. **Free plans only** (Supabase free, Netlify free). Warn before anything that could push past a free limit.
4. **No paid services or new API keys** without asking first.
5. **No em dashes or en dashes anywhere:** UI text, code comments, docs.
6. **MIT licensed code:** if you copy code from an MIT licensed repo, keep its copyright and license notice in a comment above that code.
7. **Versioning:** bump the version number shown in the app and add a dated line to CHANGELOG.md.
8. **Before saying done,** test at phone width and tell the user exactly what to tap to check it.
