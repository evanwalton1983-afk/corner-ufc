Corner Model

Loading fight history

Receiver

Both fighters of every ticked fight Corner rates on this card date are sent as one import for The War Room to record and grade. Untick fights from other promotions. Fights already under way and fighters Corner cannot rate are left out. Nothing here places a bet. If the tab does not answer, Copy JSON or Download JSON gives you the same file to import by hand.

This forecasts fights. It is not a betting tool. The last time this model was tested against closing moneylines it added no significant information beyond the price, so the Card tab shows the market next to Corner only to test that again, fight by fight, and says plainly what the record shows. A gap is something to research, not a bet.
